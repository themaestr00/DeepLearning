# Общие требования

## Общение

- Отвечать по-русски, кратко и по делу, без лишних пояснений.

## Ноутбуки и код

- Создавать только кодовые ячейки. Не добавлять текстовые/Markdown-ячейки, включая заголовки: система их не принимает.
- Не добавлять комментарии в код.
- Не добавлять `assert` и лишние проверки.
- Для загрузки CSV использовать `pandas.read_csv`.
- Для строковых литералов использовать двойные кавычки.
- Не добавлять избыточный текст в вывод ячеек.

## Обучение и оценка моделей

- Подбирать параметры по валидационной выборке. Кросс-валидацию вводить по отдельному запросу.
- После выбора лучшей модели оценивать её на тестовой выборке.
- Для финального submission обучать выбранную модель на всём доступном `train.csv` с учётом особенностей метода.
- Сохранять submission в CSV в формате предоставленного шаблона.
- Если submission содержит непрерывный `anomaly_score`, не добавлять подбор порога и сравнение с порогом по умолчанию без отдельного запроса.
